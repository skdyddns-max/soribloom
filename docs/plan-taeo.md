# 박태오 소리블룸 플랜 (2026-10-15)

**아동 특성:** 산출은 정상 범위. 지각·해독 상황에서 받침(종성) 전반이 어려움, 그중 **ㄹ 받침이 가장 취약**.
**공통 설정:** 별칭 '태오' · 60문항/세트(20문항마다 쉬어가기) · 오답 시 두 단어 다시 듣고 재시도 1회 · 글자+자모 칩 표시(해독 과제이므로 글자-소리 연결을 시각 단서로 유지).
**진급 기준:** 첫 시도 정반응 **85% 이상 2회 연속** → 다음 단계. **70% 미만 2회 연속** → 쌍 수를 줄이거나 이전 단계로.
**원칙:** 최소대립쌍(받침 유무)부터, 받침 7종을 골고루 → 데이터로 약한 받침 확인 → 집중 → 받침끼리 대립 → 청각 단서만 → 주의 부하.

| 단계 | 목표 | 쌍 구성 | 보기·글자 | 통과 |
|---|---|---|---|---|
| **1** (현재) | 받침 **유무** 변별, 7종 골고루 | 받침당 3~4쌍 = 23쌍: ㄱ 무/묵·구/국·새/색 · ㄴ 소/손·사/산·무/문 · ㄷ계열 오/옷·비/빗·소/솥·파/팥 · ㄹ 소/솔·무/물·파/팔·구/굴 · ㅁ 배/뱀·소/솜·사/삼 · ㅂ 배/밥·이/입·사/삽 · ㅇ 코/콩·사/상·벼/병 | 2택1 · 글자 표시 | 85%×2 |
| **2** | 약한 받침 **집중** (유무) | 1단계 결과에서 받침별 정확도 하위 2~3종의 쌍만 + ㄹ 추가 쌍(사/살·이/일·벼/별·나무/나물) | 2택1 · 글자 표시 | 85%×2 |
| **3** | **받침끼리** 대립 | 'ㄹ 받침 vs 다른 받침' 17쌍 + '받침끼리 대립(ㄹ 제외)' 12쌍 중 2단계에서 약했던 받침 중심 20쌍 내외 | 2택1 · 글자 표시 | 85%×2 |
| **4** | 청각 단서만 | 1~3단계 쌍 혼합 25쌍 내외 | 2택1 · **글자·자모 숨김** | 85%×2 |
| **5** | 주의 부하 | 4단계와 동일 쌍 | **3택1** · 글자 숨김 | 85%×2 |
| **6** | 유지·일반화 | 전체 받침 그룹 무작위, 주 1~2회 | 3택1 · 글자 숨김 | 유지 |

**운영 메모**
- 1단계는 60문항에 23쌍이라 쌍당 2~3회, 받침당 8~9회 노출. 받침별 정확도는 선생님 화면 '대립쌍별 누적 정확도'에서 쌍 이름 옆 받침 표시로 묶어 보면 됨.
- 단계 전환은 선생님 화면 '목표 수정'(쌍 체크·보기 수·글자 표시) → 새 링크 발송. 결과는 같은 코드(G26R9A)로 계속 쌓임.
- 2단계로 갈 때 "태오 2단계 만들어줘"라고 하면 결과를 읽어 약한 받침을 골라 설정·링크를 만들어 줌.
