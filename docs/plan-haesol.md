# 한해솔 소리블룸 플랜 (2026-11-06 갱신)

**지금까지:** ㅈ/ㄷ 변별 10회 — 7쌍·40문항·2택1(10/8~10/11, 65→85%) → 12쌍·60문항·3택1·글자 숨김(10/15~10/27, 73→95%). 10/27 57/60(95%)으로 ㅈ/ㄷ 단계 완료.

**이번 단계: 경구개 파찰음 ㅈ·ㅉ·ㅊ 삼중 대립 (평음·경음·격음), 1~3음절**
- 설정: 11세트 · **60문항** · 모든 문항 그림 3장(세 단어 세트는 ㅈ·ㅉ·ㅊ 세 단어, 두 단어 세트는 다른 세트 그림 1장 추가) · 글자·자모 숨김(순수 청각) · 오답 시 재시도 1회 · 20문항마다 쉬어가기.
- 바뀐 것은 **목표 소리 하나**뿐이고 형식(3택1·글자 숨김·60문항)은 지난 단계와 같게 유지.

- 70% 미만 2회 연속 → 3음절 세트를 빼고 1·2음절 7세트로 줄이거나, 글자 표시를 다시 켬(선생님 화면 '목표 수정').
